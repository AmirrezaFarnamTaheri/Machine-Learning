## 1. Project Overview

This project investigates computer vision architectures for dual-objective scene understanding:
1. **Multi-Class Natural Landscape Classification:** Identifying environment category across three landforms:
   - `Jungle`
   - `Mountain`
   - `Sea`
2. **Synthetic Authenticity Discrimination (Real vs. AI-Generated):** Discriminating between genuine photographic captures and synthetic outputs generated by generative diffusion models (Stable Diffusion, DALL-E).

---

## 2. Dataset Architecture

The unified dataset is located in `train/` containing 3,118 standardized images:
- **Class Balance:** Approximately equal distribution across the three landscape domains (`jungle`: 1,038, `mountain`: 1,040, `sea`: 1,040).
- **Authenticity Balance:** 50% authentic photographs and 50% text-to-image synthetic generations.
- **Unified Dual-Label Ingestion:** A single source of truth parses landscape class from parent directory taxonomy and authenticity class (`real` vs. `fake`) dynamically from filename prefixes without physical duplication.

---

## 3. Modeling Strategies

### Approach A: Custom Deep CNN (Trained from Scratch)
An 8-stage convolutional network optimized for feature hierarchy extraction:
- **Input:** $224 \times 224 \times 3$ with dynamic data augmentation (RandomFlip, RandomRotation, RandomZoom) and $[0, 1]$ rescaling.
- **Convolutional Backbone:**
  1. $\text{Conv2D}(64, 5\times5, \text{stride}=2) \rightarrow \text{BatchNorm} \rightarrow \text{ReLU} \rightarrow \text{MaxPool}(2\times2)$
  2. $\text{Conv2D}(64, 3\times3) \rightarrow \text{BatchNorm} \rightarrow \text{ReLU}$
  3. $3 \times [\text{Conv2D}(128, 3\times3) \rightarrow \text{BatchNorm} \rightarrow \text{ReLU}]$
  4. $\text{Conv2D}(256, 3\times3, \text{stride}=4) \rightarrow \text{BatchNorm} \rightarrow \text{ReLU}$
  5. $\text{Conv2D}(256, 3\times3) \rightarrow \text{BatchNorm} \rightarrow \text{ReLU}$
  6. $\text{Conv2D}(512, 3\times3, \text{stride}=2) \rightarrow \text{BatchNorm} \rightarrow \text{ReLU}$
- **Classifier Head:** Global Average Pooling 2D $\rightarrow \text{Dropout}(0.3) \rightarrow \text{Dense}(\text{num\_classes}, \text{softmax})$.

### Approach B: Transfer Learning & Fine-Tuning
Leveraging ImageNet pre-trained representations:
1. **ResNet-152V2:** Deep residual architecture with identity shortcut mappings and pre-activation units.
2. **MobileNetV3-Large:** Efficient inverted bottleneck blocks with Squeeze-and-Excitation (SE) attention mechanisms for low-latency inference.
